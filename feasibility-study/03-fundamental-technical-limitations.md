# 03 — Fundamental Technical Limitations: Physics, Sensing, and Definitions

## 1. The Unified Metrological Error Model

Every reported measurement $y$ generated by an automated garment inspection system is the output of a coupled physical, optical, and algorithmic chain. To understand why past attempts achieved only ~80% accuracy, the total measurement variance must be decomposed into its constituent physical and mathematical sources.

Following the principles of the **Guide to the Expression of Uncertainty in Measurement (JCGM 100:2008 / GUM)**, the combined standard uncertainty $u_c$ on a measured dimension is modeled as:

$$u_c^2 = u_A^2 + u_B^2 + u_C^2 + u_D^2 + u_E^2 + u_F^2$$

$$\text{with Reference Validation Error: } u_{\text{total}}^2 = u_c^2 + u_G^2$$

```
┌────────────────────────────────────────────────────────────────────────┐
│                      UNIFIED ERROR DECOMPOSITION                       │
├────┬────────────────────────┬──────────────────────────────────────────┤
│Code│ Variance Component     │ Physical / Algorithmic Origin            │
├────┼────────────────────────┼──────────────────────────────────────────┤
│ u_A│ Definitional           │ Incomplete POM operator; ambiguity in    │
│    │ Uncertainty            │ datums, direction, or feature boundaries │
├────┼────────────────────────┼──────────────────────────────────────────┤
│ u_B│ Garment State          │ Handling strain, viscoelastic hysteresis,│
│    │ Variability            │ table friction, wrinkles, seam roll      │
├────┼────────────────────────┼──────────────────────────────────────────┤
│ u_C│ Sensing & Optical      │ Perspective parallax (h/H), distortion,  │
│    │ Chain Uncertainty      │ calibration drift, depth sensor noise    │
├────┼────────────────────────┼──────────────────────────────────────────┤
│ u_D│ Physical Feature       │ Fiber fuzz, rounded fold radius, stitch  │

├────┼────────────────────────┼──────────────────────────────────────────┤
│ u_F│ Algorithmic Prior Bias │ Shrinkage toward nominal; symmetry       │
│    │                        │ constraints masking real defects         │
├────┼────────────────────────┼──────────────────────────────────────────┤
│ u_G│ Reference Measurement  │ Inherent uncertainty of the manual tape  │
│    │ Error                  │ or ground-truth verification standard    │
└────┴────────────────────────┴──────────────────────────────────────────┘
```

### Critical Axioms Governing the Error Model:
1. **$u_A$ and $u_B$ are Properties of the Textile and the Specification, NOT the Sensor:** No neural network, structured-light camera, or laser scanner can reduce $u_A$ or $u_B$. They represent physical and contractual boundaries.
2. **Component $u_E$ Exhibits a Heavy-Tailed Error Distribution:** While optical and mechanical errors ($u_B, u_C, u_D$) are roughly Gaussian, learned neural models occasionally produce catastrophic gross errors (e.g., mistaking a front collar fold for a back collar seam). A Gaussian budget cannot capture these outliers; they must be managed via explicit epistemic uncertainty and **selective abstention**.
3. **Reference Error $u_G$ Inflates Apparent System Error:** If an automated system with $u_c = 1.0\text{ mm}$ is validated against an uncalibrated manual tape inspector whose reproducibility is $u_G = 3.0\text{ mm}$, the apparent root-mean-square difference will be $\sqrt{1^2 + 3^2} = 3.16\text{ mm}$. The evaluator will incorrectly blame the automated system for the human inspector's variance `[I]`.

### 2.2 Perspective Distortion and Out-of-Plane Relief

In a monocular pinhole camera system mounted at height $H$ looking down at a table plane ($Z=0$), any garment feature elevated by height $h$ above the table experiences radial perspective displacement $\Delta r$ relative to the optical principal point `[I]`:

$$\Delta r = r \cdot \frac{h}{H - h}$$

where $r$ is the radial distance from the principal point in the image plane. Furthermore, a horizontal feature of length $L$ lying at elevation $h$ appears enlarged by the scale factor:

$$\frac{\Delta L}{L} = \frac{h}{H - h} \approx \frac{h}{H}$$

```
                Camera Center
                     ●
                    /|\
                   / | \
                  /  |  \
                 /   |H  \
                /    |    \
   Garment Relief    |     \
  ┌──────────────┐   |      \
  │h             │   |       \
══╧══════════════╧═══╪════════●════════ Table Plane (Z=0)
       r_true        |      r_apparent
                     |◄──────►|
                        Δr (Parallax Error)
```

In production garments, a "flat-laid" garment is **not a 2D sheet**. It exhibits significant 3D relief:
- Single fabric plies: $0.5\text{ mm to }1.5\text{ mm}$ thickness.
- Multi-layer seam junctions, hems, and cuffs: $3\text{ mm to }6\text{ mm}$.
- Ribbed knit collars, denim waistbands, and cargo pocket flaps: **$6\text{ mm to }15\text{ mm}$ elevation**.

This is why Claude's proposal to discard all 3D sensing is scientifically flawed: **topographic height data is mathematically required to orthorectify 2D planar measurements**.

### 2.3 Mathematical Proof: Depth Sensor Noise Inflates Geodesic Surface Length

A seductive hypothesis in 3D computer vision is that a structured-light camera can "measure true fabric length across wrinkles" by computing the geodesic arc length across the 3D point cloud mesh. 

**We prove from first principles that this hypothesis is mathematically flawed: depth noise systematically inflates Euclidean arc length `[I]`.**

#### Mathematical Proof:
Consider a 1D surface profile sampled at regular lateral spatial intervals $a$ along the $X$-axis: $x_i = i \cdot a$ for $i = 0, 1, \dots, N$.
Let the true surface be perfectly flat: $z_{\text{true}}(x) = 0$.
The true horizontal length over $N$ steps is $L_{\text{true}} = N \cdot a$.

Assume the depth sensor introduces zero-mean independent Gaussian depth noise with standard deviation $\sigma_z$:
$$\hat{z}_i = z_{\text{true}}(x_i) + \epsilon_i = \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma_z^2)$$

The measured Euclidean distance between two adjacent 3D points in the point cloud is:
$$\Delta s_i = \sqrt{(x_{i} - x_{i-1})^2 + (\hat{z}_i - \hat{z}_{i-1})^2} = \sqrt{a^2 + (\Delta z_i)^2}$$

where $\Delta z_i = \epsilon_i - \epsilon_{i-1}$. Since $\epsilon_i$ and $\epsilon_{i-1}$ are independent Gaussian variables, their difference is Gaussian:
$$\Delta z_i \sim \mathcal{N}(0, 2\sigma_z^2)$$

Let $v = (\Delta z_i)^2$. Then $v$ follows a scaled Chi-square distribution with 1 degree of freedom: $v \sim 2\sigma_z^2 \chi_1^2$.
Expanding the step length $\Delta s_i$ in a Taylor series about $(\Delta z_i)^2 = 0$:
$$\Delta s_i = a \sqrt{1 + \frac{(\Delta z_i)^2}{a^2}} \approx a \left[ 1 + \frac{1}{2}\frac{(\Delta z_i)^2}{a^2} - \frac{1}{8}\frac{(\Delta z_i)^4}{a^4} + \dots \right]$$

Taking the mathematical expectation:
$$\mathbb{E}[\Delta s_i] \approx a \left[ 1 + \frac{1}{2a^2}\mathbb{E}[(\Delta z_i)^2] - \frac{1}{8a^4}\mathbb{E}[(\Delta z_i)^4] \right]$$

Since $\mathbb{E}[(\Delta z_i)^2] = 2\sigma_z^2$ and $\mathbb{E}[(\Delta z_i)^4] = 3 \cdot (2\sigma_z^2)^2 = 12\sigma_z^4$:
$$\mathbb{E}[\Delta s_i] \approx a \left[ 1 + \frac{\sigma_z^2}{a^2} - \frac{3}{2}\frac{\sigma_z^4}{a^4} \right] > a$$

The total expected measured surface path length $\hat{L} = \sum_{i=1}^N \Delta s_i$ is:
$$\mathbb{E}[\hat{L}] \approx N \cdot a \left( 1 + \frac{\sigma_z^2}{a^2} \right) = L_{\text{true}} \left( 1 + \frac{\sigma_z^2}{a^2} \right)$$

$$\text{Fractional Systematic Length Inflation: } \frac{\mathbb{E}[\hat{L}] - L_{\text{true}}}{L_{\text{true}}} \approx \left(\frac{\sigma_z}{a}\right)^2$$

$$\text{Q.E.D.}$$

#### Quantitative Simulation of Depth Noise Length Inflation:
Evaluating this formula across sensor configurations demonstrates the catastrophic scale of this systematic bias `[I]`:

| Lateral Spatial Step $a$ | Depth Noise $\sigma_z$ | Depth Noise Ratio ($\sigma_z / a$) | Expected Systematic Length Inflation | Measured Length on $700\text{ mm}$ True Span |
|---|---|---|---|---|
| **$0.44\text{ mm}$** (Zivid 2+ L110 native) | **$0.26\text{ mm}$** (Datasheet precision `[E]`) | **$0.591$** | **$+26.6\%$** | **$886.2\text{ mm}$ ($+186.2\text{ mm}$ error!)** |
| **$1.00\text{ mm}$** (Subsampled mesh) | **$0.26\text{ mm}$** (Zivid precision) | **$0.260$** | **$+6.2\%$** | **$743.4\text{ mm}$ ($+43.4\text{ mm}$ error)** |
| **$2.00\text{ mm}$** (Filtered mesh) | **$0.26\text{ mm}$** (Zivid precision) | **$0.130$** | **$+1.7\%$** | **$711.9\text{ mm}$ ($+11.9\text{ mm}$ error)** |
| **$1.00\text{ mm}$** | **$0.05\text{ mm}$** (Ultra-high-end metrology 3D) | **$0.050$** | **$+0.25\%$** | **$701.8\text{ mm}$ ($+1.8\text{ mm}$ error)** |

#### Metrological Conclusion:
Summing unregularized 3D surface point clouds directly inflates lengths by tens to hundreds of millimetres. 
To eliminate this inflation, the 3D surface must be aggressively smoothed using spatial low-pass filtering or spline fitting. However, **low-pass filtering smooths out the actual fabric wrinkles the 3D camera was purchased to measure**!
Therefore, 3D point cloud surface integration is a regularisation trap. Depth data is useful *strictly* for elevation orthorectification, never for raw geodesic path summation.

## 3. Garment Physics and Material Science Limits (Component $u_B$)

### 3.1 Fabric Mechanics: Table Friction vs Elastic Recovery
When an operator smooths a garment onto an inspection table, their hands impart in-plane tensile and shear stresses. In classical mechanics, an elastic body returns to its undeformed state when released. Why does this fail for garments?

Textile fabrics are non-linear viscoelastic sheets governed by low-stress mechanics characterized by the **Kawabata Evaluation System (KES-FB)** and **SiroFAST** `[E, FAST/KES]`:
- Initial tensile modulus is extremely low under loads $< 5\text{ gf/cm}$ ($0.05\text{ N/cm}$).
- Tensile recovery exhibits severe **hysteresis** (energy dissipation via yarn-on-yarn friction).

When the operator releases the fabric, the restoring elastic force per unit width is $T_{\text{elastic}} = E \cdot \epsilon$.
The resisting static frictional shear force per unit width exerted by the table is:
$$T_{\text{friction}} = \mu \cdot \rho_A \cdot g \cdot L_{\text{contact}}$$

where $\mu$ is the fabric-table friction coefficient ($\approx 0.3\text{ to }0.6$), $\rho_A$ is fabric areal mass ($150\text{ to }400\text{ g/m}^2$), $g = 9.81\text{ m/s}^2$, and $L_{\text{contact}}$ is the continuous contact length from the edge ($\approx 0.2\text{ to }0.5\text{ m}$) `[I]`:

$$T_{\text{friction}} = (0.5) \cdot (0.200\text{ kg/m}^2) \cdot (9.81\text{ m/s}^2) \cdot (0.3\text{ m}) = 0.294\text{ N/m} = 0.030\text{ gf/cm}$$

```
                Friction vs Elastic Recovery Threshold
   Load (gf/cm)
     ▲
     │
 5.0 ┼──────────────────────────────────── Standard FAST E5 Test Threshold
     │
 1.0 ┼────────────────────────────────────
     │
 0.1 ┼─── Friction Hold Threshold (~0.03 - 0.09 gf/cm)
     │   (Table friction holds fabric in strained state)
 0.0 └────────────────────────────────────► Strain ε (%)
```

#### The Hysteretic Lock-In Mechanism:
The table friction threshold ($0.03\text{ to }0.09\text{ gf/cm}$) is **two orders of magnitude lower** than standard fabric testing loads ($5\text{ gf/cm}$) `[I]`.
- Elastic forces below this frictional threshold cannot overcome table friction.
- Consequently, **any in-plane strain introduced by the operator during smoothing is permanently locked into the garment by friction**.
- "Flat without tension" is therefore a physical impossibility on a standard table. The garment's resting dimension is a function of its handling history. This accounts for **$1.5\text{ mm to }4.0\text{ mm}$ of intermediate precision variance ($u_B$)** across independent re-lays.

### 3.2 Wrinkles and Folds: Projected Length vs True Fabric Length

A camera mounted above a flat table measures the **orthogonal projection** of the garment onto the $XY$-plane. Any out-of-plane wrinkle or fold conceals true fabric length, causing the camera to measure **systematically short**.

#### Mathematical Formulation for a Wrinkle Field:
Model a continuous field of fabric wrinkles along a measurement axis as a sinusoid:
$$z(x) = A \sin\left(\frac{2\pi x}{\lambda}\right)$$

where $A$ is the wrinkle amplitude and $\lambda$ is the spatial wavelength.
The true fabric arc length $S$ over projected span $L$ is:
$$S = \int_0^L \sqrt{1 + \left(\frac{dz}{dx}\right)^2} dx = \int_0^L \sqrt{1 + \left(\frac{2\pi A}{\lambda}\right)^2 \cos^2\left(\frac{2\pi x}{\lambda}\right)} dx$$

Using the binomial approximation for small slopes $\left(\frac{2\pi A}{\lambda} \ll 1\right)$:
$$\sqrt{1 + \epsilon} \approx 1 + \frac{1}{2}\epsilon \implies S \approx \int_0^L \left[ 1 + \frac{1}{2}\left(\frac{2\pi A}{\lambda}\right)^2 \cos^2\left(\frac{2\pi x}{\lambda}\right) \right] dx$$

Since the average value of $\cos^2(\theta)$ over full cycles is $\frac{1}{2}$:
$$S \approx L \left[ 1 + \left(\frac{\pi A}{\lambda}\right)^2 \right]$$

$$\text{Fractional Projected Length Loss: } \frac{S - L}{S} \approx \left(\frac{\pi A}{\lambda}\right)^2$$

The table below calculates the exact projected length lost across realistic wrinkle profiles `[I]`:

| Wrinkle Profile Type | Amplitude / Height ($A$ or $a$) | Wavelength / Base ($\lambda$ or $b$) | Projected Length Lost ($\%$) | Dimensional Loss on $700\text{ mm}$ POM |
|---|---|---|---|---|
| **Micro-ripple (barely visible)** | $0.5\text{ mm}$ | $50\text{ mm}$ | **$0.10\%$** | **$0.70\text{ mm}$** |
| **Low gentle wave** | $1.0\text{ mm}$ | $50\text{ mm}$ | **$0.39\%$** | **$2.73\text{ mm}$** |
| **Moderate wave** | $1.0\text{ mm}$ | $30\text{ mm}$ | **$1.08\%$** | **$7.56\text{ mm}$** |
| **Pronounced wrinkle** | $2.0\text{ mm}$ | $40\text{ mm}$ | **$2.37\%$** | **$16.59\text{ mm}$** |
| **Isolated seam ridge** | $3.0\text{ mm}$ height | $20\text{ mm}$ base | — | **$0.87\text{ mm}$ per ridge** |

#### Crucial QC Implication:
- **Wrinkles Produce a Strictly One-Sided Asymmetric Bias:** Wrinkles **always shorten** projected dimensions; they can never make a garment appear longer.
- In a factory QC setting, this creates a severe systematic error: **conforming garments are falsely classified as out-of-tolerance (short), while oversized garments are masked as conforming**!

### 3.3 The Physics of Why Open Vacuum Tables Fail on Finished Garments

In Chapter 00, we exposed the technical flaw in Claude's proposal to use perforated vacuum tables (Architecture A6). Here, we formalize the fluid and contact mechanics of why this fails `[I]`:

1. **Air Permeability and Pressure Head Collapse:**
   - In fluid mechanics, airflow through a porous textile obeys the Darcy-Forchheimer equation:
     $$\Delta P = \frac{\mu_{\text{air}}}{K} v \cdot t_{\text{fabric}} + \rho_{\text{air}} C v^2 t_{\text{fabric}}$$
     where $K$ is fabric permeability ($10^{-10}\text{ to }10^{-8}\text{ m}^2$) and $v$ is superficial face velocity.
   - For standard knitted cotton ($K \approx 5 \times 10^{-9}\text{ m}^2$), a commercial vacuum blower with flow rate $Q = 500\text{ m}^3/\text{h}$ operating over a $1.5\text{ m}^2$ open table generates a pressure drop across the fabric of:
     $$\Delta P < \mathbf{0.08\text{ kPa}} \ (0.0008\text{ bar})$$
   - This downward pressure ($80\text{ N/m}^2 \approx 8\text{ gf/cm}^2$) is **two orders of magnitude weaker** than the bending rigidity required to flatten a double-folded denim hem or an ironed cotton crease!
2. **Local Dimpling Distortion:**
   - Where the porous knit fabric spans across a $5\text{ mm}$ vacuum hole, the air drag forces the fabric into the hole, creating a microscopic spherical dome (dimpling).
   - This dimpling pulls fabric inward from the perimeter, **shortening the apparent outer boundary by $1\text{–}3\text{ mm}$** while creating scalloped edge distortions.
3. **Frictional Normal Force Amplification:**
   - If vacuum suction is active while an operator attempts to smooth a garment, the effective normal force $N = (mg + \Delta P \cdot A)$ increases friction, **locking in wrinkles and preventing manual relaxation**.

## 5. Prior Bias: The Affine Strain Tensor Formulation

To prevent the dangerous phenomenon of **shrinkage toward nominal** (Chapter 03 §5.2), CAD pattern data must be utilized strictly as a topological constraint, not a coordinate snapper.

Let a 2D CAD pattern piece be defined in undeformed material coordinates $\mathbf{X} = (X, Y)^T \in \Omega_0$.
When sewn and laid on the table, the fabric undergoes a deformation mapping $\mathbf{x} = \phi(\mathbf{X}) \in \mathbb{R}^2$.
The **deformation gradient tensor** is:
$$\mathbf{F} = \frac{\partial \mathbf{x}}{\partial \mathbf{X}} = \begin{bmatrix} \frac{\partial x}{\partial X} & \frac{\partial x}{\partial Y} \\ \frac{\partial y}{\partial X} & \frac{\partial y}{\partial Y} \end{bmatrix}$$

The Green-Lagrange **finite strain tensor** $\mathbf{E}$ measures true physical stretching independent of rigid-body rotation:
$$\mathbf{E} = \frac{1}{2} \left( \mathbf{F}^T \mathbf{F} - \mathbf{I} \right)$$

```
        UNDEFORMED PATTERN (CAD)            DEFORMED GARMENT ON TABLE
        ┌─────────────────────────┐          ┌───────────────────────────┐
        │   E_XX = 0, E_YY = 0    │   ──►    │  E_XX = +3.2% (Stretched) │
        │   (Rigid Nominal)       │  Strain  │  E_XY = -1.8% (Sheared)   │
        └─────────────────────────┘          └───────────────────────────┘
```

#### The Deformation-Invariant QC Rule:
Instead of forcing observed contours to match the nominal CAD shape, the system computes the local strain components $E_{XX}$ (warp strain), $E_{YY}$ (weft strain), and $E_{XY}$ (shear strain) across the fabric surface:
1. If $\text{Tr}(\mathbf{E}) > 0.04$ ($>4\%$ tensile strain), the system detects that the operator **over-stretched the garment during smoothing**, triggering an automated lay invalidation!
2. If $\mathbf{E} \approx \mathbf{0}$, the garment is confirmed in a relaxed state, allowing sub-pixel GPS measurement to execute without regularization bias `[I]`.
